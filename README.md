# Elele Medical Mission Dashboard Report

A single-page HTML report summarizing the 1-Day Free Medical Mission held at
Elele Medium Security Correctional Farm Centre on July 21, 2026, organized by
the O.B. Lulu-Briggs Foundation.

## View the live report

Once GitHub Pages is enabled for this repo, the report is available at:

```
https://dakozy.github.io/elele-free-medical-mission/elele-medical-mission-report.html
```

## Contents

- `elele-medical-mission-report.html` — the full dashboard report (patient
  stats, sex/age distribution, top diagnoses, medicines dispensed, RVS and
  malaria screening results)

## Notes

- Charts and the foundation logo are hosted externally as images
  (postimg.cc) and loaded via direct links in the HTML — no separate image
  files are needed in this repo.
- This file is also formatted to be copy-pasted directly into Gmail as a
  standalone email.

## Source data

At a glance: 130 patients seen (95 male / 35 female), 76% with age recorded,
60% diagnosed with malaria, 35 lab tests run.
